MAKE THE CONNECTION

A little setup.
A world of questions.

The app owner can connect AI in three steps:

  1. Copy .env.example to .env.
  2. Add a funded OpenAI API key as OPENAI_API_KEY. Keep it on the server.
  3. Restart with npm start and refresh this page.

Web sources use OpenAI’s hosted web search. No separate search key is needed. Set WEB_SEARCH=false for answers without live research. Model and billing access are required.

Questions are sent to OpenAI when you explore. Saved answers and your notes stay on this device. Avoid sharing personal information.
